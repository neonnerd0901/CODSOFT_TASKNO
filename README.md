# CODSOFT Java Programming Internship

This repository contains the Java programming tasks completed as part of the **CodSoft Java Development Internship**.

## Tasks Completed

### Task 1 - Number Guessing Game
#### Description
A Java console application that generates a random number and asks the user to guess it.

#### Features
- Random number generation
- User input using Scanner
- Hints (Too High / Too Low)
- Multiple attempts
- Score calculation

#### Technologies Used
- Java
- VS Code
- Git & GitHub

---

### Task 2 - Student Grade Calculator
#### Description
A Java application that calculates the total marks, percentage, and grade based on marks entered by the user.

#### Features
- Input marks
- Total marks calculation
- Percentage calculation
- Grade calculation
- Result display

#### Technologies Used
- Java
- VS Code
- Git & GitHub

---

### Task 4 - Quiz Application
#### Description
A Java console-based quiz application with multiple-choice questions and a timer.

#### Features

- Final result with percentage

#### Technologies Used
- Java
